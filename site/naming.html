Name a function

Open a function to see who calls it, what it calls and the identifier-like strings it points at, then propose a name: the button opens a GitHub issue with the address filled in. Sly 1 match and Rust port names have outside evidence; provisional names are readings of the code and are the ones most worth a second look. Names and addresses only: no game data is published here.

The code of Sly 2 belongs to Sucker Punch Productions and Sony Interactive Entertainment. This page lists names, addresses, sizes, call relations and a few identifier-like strings for interoperability and preservation. Tooling is GPL-3.0-or-later; see THIRD_PARTY_NOTICES.md in the repository.
